Design specific for Bambu Lab X1’s official 256 × 256 × 256 mm build volume. The largest part is only 183.7 × 105 mm.

[Download the STL-only package](https://github.com/fwijnholds/bror-divider/edit/main/drawer-divider-x1-honeycomb-stls.zip)

Print quantities
- 4× [Honeycomb side panel](https://raw.githubusercontent.com/fwijnholds/bror-divider/refs/heads/main/drawer-divider-x1-honeycomb-stls/honey_side_panel_182_5mm.stl)
- 3× [Honeycomb front rail panel](https://raw.githubusercontent.com/fwijnholds/bror-divider/refs/heads/main/drawer-divider-x1-honeycomb-stls/honey_front_rail_panel_183_7mm.stl)
- 3× [Honeycomb front segmentation panel](https://raw.githubusercontent.com/fwijnholds/bror-divider/refs/heads/main/drawer-divider-x1-honeycomb-stls/honey_front_segment_panel_107_4mm.stl)
- 8× [Straight slide clip](https://raw.githubusercontent.com/fwijnholds/bror-divider/refs/heads/main/drawer-divider-x1-honeycomb-stls/straight_slide_clip.stl)
- 10× [T slide clip](https://raw.githubusercontent.com/fwijnholds/bror-divider/refs/heads/main/drawer-divider-x1-honeycomb-stls/straight_slide_clip.stl)

This creates:
- Four front compartments, approximately 136 × 109 mm each
- Two full-depth side compartments
- One large open center/rear compartment
- 105 mm-high panels
- Open 1.8 mm honeycomb ribs with solid coupling rails
- Support-free, flat printing
Print one extra of each clip type as a spare.
